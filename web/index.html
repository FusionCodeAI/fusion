❓ Terminal Shortcuts & Slash Commands

Keyboard Shortcuts

EnterSubmit prompt to agent
Ctrl + CInterrupt active streaming turn or clear input
Ctrl + LClear terminal screen
TabAuto-complete slash commands
▲ / ▼Navigate command history
Ctrl + A / EJump to start / end of line
Ctrl + UDelete entire line

Supported Slash Commands

  • /help — Show command summary and active configuration
  • /model [name] — Open model picker or switch active model
  • /subagent <task> — Fan-out parallel subagents (scout, reviewer, simplifier)
  • /tools — List and test available tools (grep, glob, bash, edit, file)
  • /cost — View token usage metrics and estimated session cost
  • /compact — Compact context window to prevent overflow
  • /advisor — Evaluate security and performance guardrails
  • /checkpoint — Serialize session state to JSON
  • /restore — Restore session state from checkpoint JSON
  • /clear — Clear terminal output
