# Build LaTeX Paper to PDF

This script compiles `fusion-paper.tex` into `fusion-paper.pdf`.

## Prerequisites
- `pdflatex` or `tectonic` or `latexmk` installed.

## Compile
```bash
cd docs/paper
pdflatex fusion-paper.tex
pdflatex fusion-paper.tex
```
*(Run twice for cross-references and citations).*
